# FN软仓服务端 (fn-appstores-server) 使用指南

欢迎使用 FN软仓服务端！本服务端是专为飞牛 fnOS 打造的第三方应用商店后端，让你能够在自己的 NAS 上搭建完全私有的应用分发中心。

## 1. 登录后台管理系统

- **访问地址**：`http://你的NAS_IP:5660/admin`
- **管理员账号**：`admin`
- **管理员密码**：安装时在向导中填写的 `ADMIN_PASSWORD`（默认 `admin`）

> **⚠️ 注意**：如果页面打不开，请检查飞牛防火墙是否放行了 `5660` 端口，或者在飞牛 Docker 容器列表中查看端口映射情况。

## 2. 上传并上架你的应用

登录后台后，你可以将自己打包好的 `.fpk` 应用（比如自己写的 File Vault）分发出去：

1. 在左侧菜单找到 **“应用管理”** -> **“应用列表”**。
2. 点击 **“上传应用”**，将你打包好的 `.fpk` 文件拖拽进去。
3. 系统会自动解析 FPK 包内的应用图标、名称、版本号和简介。
4. 上传完成后，确保将应用状态设置为 **“上架”** 或 **“公开”**。

## 3. 获取你的“专属订阅链接”

这是客户端能够连上你商店的关键：

1. 在后台的仪表盘或 **“系统设置”** 中，找到 **“商店订阅地址”**（通常以 `.json` 结尾，例如 `http://你的NAS_IP:5660/api/store.json`）。
2. 复制这个链接。这就是你的“私有源地址”。

## 4. 客户端接入（在飞牛上使用）

用户（或者你自己）需要在飞牛设备上安装 **FN软仓客户端**。

1. 打开客户端，进入 **“源管理”** 或 **“添加第三方源”**。
2. 将刚才获取的 **“专属订阅链接”** 粘贴进去。
3. 保存并刷新客户端。此时，你后台里的应用就会出现在客户端的列表中。
4. 点击下载，即可直接从你的 NAS 拉取应用包并一键安装。

## 5. 进阶配置与说明

- **修改 BASE_URL**：如果后续更换了域名或穿透地址，可以在飞牛的 Docker 管理器中，修改容器的 `BASE_URL` 环境变量（例如 `http://新的IP:5660`），然后重启容器。
- **公告管理**：登录后台后，可以发布系统公告，客户端会推送给所有连接此源的设备。
- **数据备份**：你的所有数据库文件都安全地保存在飞牛的 `@appdata` 安全区。升级或重装应用不会丢失配置。
